We've given the site a fresh coat of paint with some serious performance upgrades under the hood.

**What's new:**

- **Blazing fast background**: The new background image is optimized to just 8KB using WebP format, ensuring instant loads even on slower connections.
- **Crisp visuals**: All images have been converted to WebP with transparency support, maintaining quality while drastically reducing file sizes.
- **Fresh typography**: The button now features the retro VT323 font in bright pink, giving it a distinct look.
- **Circular favicon**: A new rounded favicon that stands out in your browser tabs.
- **Zero bloat**: This is a pure static site. No databases, no heavy frameworks, just raw speed and responsiveness.

Everything you love about the content remains unchanged. For more technical details on how we achieved this performance, check out the README.md.
